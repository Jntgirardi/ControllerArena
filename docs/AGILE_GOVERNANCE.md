# Gestão Ágil e Governança - FPS Arena

## Método Escolhido

O time adotou **Scrum**.

## Justificativa da Escolha

Scrum foi escolhido porque:

- o projeto possui um objetivo de MVP claro
- o trabalho pode ser dividido em incrementos curtos
- a equipe consegue revisar entregas de forma frequente
- a disciplina pede evidência de organização, papéis e backlog priorizado

## Cerimônias Adotadas

### Sprint Planning

- definição das histórias da sprint
- alinhamento técnico
- distribuição de responsáveis

### Daily

- status rápido
- bloqueios
- próximos passos

### Sprint Review

- demonstração do incremento funcional
- validação com base nos critérios de aceite

### Retrospectiva

- o que funcionou
- o que precisa melhorar
- ajuste do processo para a próxima sprint

## Quadro de Trabalho

Estrutura sugerida para Jira ou ClickUp:

- Backlog
- To Do
- In Progress
- Testing/Review
- Done

## Fluxo de Trabalho

1. História criada no backlog
2. Priorização pelo Product Owner
3. Seleção para a sprint
4. Desenvolvimento
5. Teste e revisão
6. Conclusão com atualização do quadro

## Definition of Done

Uma tarefa só é considerada pronta quando:

- possui responsável definido
- tem critério de aceite atendido
- está funcional no ambiente local
- não apresenta erro crítico no fluxo principal
- foi revisada pelo time
- teve status atualizado no board

## Evidências Esperadas para a Apresentação

- board no Jira ou ClickUp
- histórias com critérios de aceite
- responsáveis por tarefa
- sprint ou prioridade atribuída
- tarefas concluídas no fluxo real do time
